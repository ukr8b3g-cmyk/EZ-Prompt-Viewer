# EZ Prompt Viewer v1.2.0

## Highlights

- H3 legacy, H3 Reference, and Qwen Image 2.1 Character Sheet Designer reconstruction from saved `state_json`, with pinned compiler provenance
- Official native-subgraph workflows, nested links, and H3 BasicGuider / SamplerCustomAdvanced routing
- More reliable metadata selection, Unicode, active switch paths, and bounded JSON parsing
- Manual edits survive language changes and formatting; stale folder/Civitai requests are cancelled
- Bounded metadata caching and lazy thumbnails for lower folder-browsing memory use

## 日本語

- H3 legacy / H3 Reference / Qwen Image 2.1 Character Sheet Designer の保存済み状態からの再構築に対応
- 公式サブグラフ、入れ子のリンク、H3 の生成経路を正しく追跡
- 文字化け、メタデータ選択、分岐解析、手編集の保持、フォルダ表示の応答性を改善

再構築したプロンプトには使用した固定版コンパイラと「再構築」を表示します。未知のコンパイラで実行された原文の完全復元を保証するものではありません。画像に保存されていないメタデータは復元できません。

## Download and verification

- `EZ-Prompt-Viewer-Setup.exe`: Windows x64 NSIS installer
- `SHA256SUMS.txt`: SHA-256 checksum
- Electron 44.4.5 / electron-builder 26.16.1
- Automated regression, pinned Python compiler comparisons, Chromium smoke, and an installed Electron smoke test run before publication
- The existing application ID, installation behavior, icons, and shortcut name are retained. There is no automatic updater; download and run the new installer to update.
- Previous releases remain available and are not replaced.

The Windows installer is unsigned. Windows may show a publisher or SmartScreen warning. A checksum confirms file integrity, not publisher identity. Manual Windows desktop testing and ComfyUI/GPU image generation were not performed for this release.
